# student-record-manager
A Python CLI application for managing, searching, and analyzing student records with multi-format file support (TXT, CSV, JSON).

Student Record Management System is an object-oriented Python CLI tool designed to store, manage, and query student performance data. It supports seamless importing/exporting across TXT, CSV, and JSON file formats, automatically calculates totals, averages, and pass/fail statuses, and offers single-criterion and multi-condition search filtering.
